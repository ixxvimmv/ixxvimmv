## 💫 About Me

I'm a self-driven developer who builds things to learn, then polishes them until they feel good to use. I care about how an app **looks** just as much as how it **works**, so I design my own interfaces before I code them.

- 🛠️ **Building:** personal projects, like [No One Reads This](https://ixxvimmv.github.io/if-no-one-reads-this/), a website I designed and built myself
- 🌱 **Learning:** databases and APIs, so I can turn my front-end projects into complete full-stack apps
- 🎨 **Design side:** I plan layouts and visuals in Canva before writing a single line of code
- 🤖 **Tinkering:** I also experiment with hardware using Arduino
- 💬 **Ask me about:** web development, UI design, or getting started with your first project
